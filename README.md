# HindiLexicography

_Created: 09-07-2026 · Last updated: 11-07-2026_

Digitization workspace for Hindi lexicography — the repository's GitHub
description reads **«Оцифровка двухтомника»** ("Digitization of a two-volume
set").

## Status

**Newly created and not yet populated.** As of the date above the repository
contains no data, source scans, transcriptions, or tooling — this README is the
first committed file. The lines below record only what is currently known for
certain; specifics (the exact dictionary, its editions, scan sources, output
format, and pipeline) will be filled in as the digitization work begins.

## What this repository is for

- A **data and digitization workspace** for a two-volume Hindi lexical work,
  in the spirit of the sibling lexicography repositories under the
  [gasyoun](https://github.com/gasyoun) account (e.g.
  [SanskritLexicography](https://github.com/gasyoun/SanskritLexicography)).
- Scope, source identification, and the digitization pipeline are **to be
  defined**. Do not assume a specific title, edition, or method until it is
  recorded here.

## Conventions

Org-level conventions for this account's lexicography repositories — Markdown
authoring rules, the `.ai_state.md` session-journal protocol, and Windows/
encoding notes — are defined in the parent
[`CLAUDE.md`](https://github.com/gasyoun/SanskritLexicography/blob/main/CLAUDE.md)
and are loaded automatically by tooling working across these repositories.

When the first real content lands, replace the **Status** section above with a
